# Box art sources

Source files for the drawn box's bottom text. The program uses only a picture made from them, not the fonts.

* `GCE_bottom_text.tif` - the bottom text of a GCE box (THIS PACKAGE CONTAINS ... / FOR USE WITH THE VECTREX
  ARCADE SYSTEM. / GCE / ENTERTAINING NEW IDEAS), by Hugo Bokhorst, made with the two fonts below.
* `fonts/CleanSweepLabel.ttf` - "Clean Sweep Label": URW Gothic Book (urw-base35-fonts, URW Software /
  URW++), modified by Hugo Bokhorst to match the lettering on the Clean Sweep box. Licence: AGPL-3.0 with the
  URW font exception (`fonts/AGPL-3.0.txt`; the full notice is inside the font). The build source is in its SRC table.
* `fonts/CleanSweepTagline.ttf` - "Clean Sweep Tagline", by Hugo Bokhorst (the ENTERTAINING NEW IDEAS line).
* `fonts/texgyreheros-bold.otf` - TeX Gyre Heros Bold (GUST e-foundry), used for the cartridge labels' small print
  (tools/legal_lines.py). Licence: GUST Font License / LPPL (`fonts/GUST-FONT-LICENSE.txt`).
