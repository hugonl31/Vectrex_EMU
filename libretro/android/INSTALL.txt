Vectrex_EMU core for RetroArch on Android (arm64) - with ES-DE
==============================================================

What is here (the zip, or the Google Drive folder: the same files, unpacked)
  vectrex_emu_libretro_android.so      the core
  vectrex_emu_libretro.info            its name and details for RetroArch
  system/vectrex_emu/                  the BIOS, the overlays (PNG), the switch-on / switch-off sounds
  ES-DE/custom_systems/es_systems.xml  ES-DE: Vectrex_EMU as the Vectrex system's emulator

You need the RetroArch from retroarch.com (or F-Droid), not the Google Play one: the Play Store version cannot
load a core from a file.

1. The core
   Copy vectrex_emu_libretro_android.so to the device (Downloads is fine). In RetroArch:
   Main Menu > Load Core > Install or Restore a Core > pick the file. RetroArch copies it into its own cores folder,
   which is where ES-DE looks for it.

2. The info file (optional: without it the core still runs, but the core list shows its file name)
   On Android RetroArch's own Core Info folder is private (no other app can copy into it). Once:
     Settings > Directory > Core Info: pick /storage/emulated/0/RetroArch/info (make the folder first),
     Main Menu > Online Updater > Update Core Info Files (all the other cores' info files into it),
     then copy vectrex_emu_libretro.info into it. The core list then shows "Vectrex_EMU".

3. The BIOS, overlays and sounds
   RetroArch: Settings > Directory > System/BIOS shows the system folder (often /storage/emulated/0/RetroArch/system).
   Copy the vectrex_emu folder from this zip's system folder into it, so you get
       <system>/vectrex_emu/bios.bin
       <system>/vectrex_emu/overlays/*.png
       <system>/vectrex_emu/on.wav, off.wav
   Speech games (VecVox / VecVoice): put sp0256-al2.bin (or al2.bin) in <system>/vectrex_emu too. Not included.
   Overlays are found by the game's file name (Armor Attack.bin -> overlays/Armor Attack.png).
   PiTrex and UVMC2: their SD cards (cards/system/vectrex_emu: pitrex_sd.img, uvmc2_sd.img) into <system>/vectrex_emu,
   the PiTrex loader (cards/ROMs/PiTrex.img - its menu starts the PiTrex programs) and the .um2 games with the games.

4. ES-DE
   Copy ES-DE/custom_systems/es_systems.xml into ES-DE's own custom_systems folder on the device
   (ES-DE/custom_systems; if one is there already, copy only its <system> part in). Restart ES-DE.
   The Vectrex system then starts games with Vectrex_EMU; vecx stays available as an alternative emulator.

Controls (RetroArch's RetroPad)
   Stick or d-pad: the joystick.  Y X B A: Vectrex buttons 1 2 3 4 (left to right, as on the controller).
   START: the overlay off / on - any other button: Quick Menu > Controls > Port 1 Controls > Overlay off / on.
   Port 2: a second pad.
   Tate (the device held upright): Core Options > Picture > Rotation; the stick and buttons 1-4 turn with it
   (Controls > Controls turned with the picture).

Settings: Quick Menu > Core Options, in submenus: Picture, Overlay, Tube, Controls, System, Sound.
   Sharpest lines: Picture > Picture size = your screen's height in pixels (Retroid Pocket 4:3: 960; 1080p: 1080;
   4K: 2160), with RetroArch's Settings > Video > Scaling > Integer Scale on - the picture then fills the screen exactly,
   one core pixel per screen pixel (also in tate). Bilinear Filtering off.
   Picture area auto: the whole overlay with an overlay on, the glass window (a larger picture) without.
   50 Hz (the game's own rate) needs a screen that can run at 50 Hz (Sync to Exact Content Framerate on).
   If a game runs slow: the device's performance mode up, Phosphor glow off, a smaller Picture size.

Trouble: the core writes <system>/vectrex_emu/vectrex_emu.log on every game start (the BIOS and overlay it found).
