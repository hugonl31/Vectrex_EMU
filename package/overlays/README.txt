The screen overlays: the MiSTer Vectrex core's set (https://github.com/Videodr0me/Vectrex_MiSTer, its
overlays.zip), renamed like the games (RENAMED.txt); CREDITS.md names each design's author. Armor Attack.bin
finds Armor Attack.art. "Steel Siege.png" is the overlay of the included Steel Siege. Your own go here too: MiSTer .art files (their own names are found too) or PNG images.

"Mine Storm (built in).art" is the overlay for the console's own game, Mine Storm. A "Mine Storm.art" of
your own is chosen before it; or replace / delete that file (without it Mine Storm runs without an overlay).
See README.md on GitHub: https://github.com/hugonl31/Vectrex_EMU#overlays
