Put screen overlays here: MiSTer .art files or PNG images, named like the ROM.
  Armor Attack.bin finds Armor Attack.art (or MiSTer's own name, ArmorAttack.art / Armor_Attack.art).
Get them from the MiSTer Vectrex core: https://github.com/Videodr0me/Vectrex_MiSTer (overlays.zip;
only the normal files are needed, not the _90CW / _90CCW ones in its Tate folder). Mine Storm's overlay
is already built in. See README.md on GitHub: https://github.com/hugonl31/Vectrex_EMU#overlays
